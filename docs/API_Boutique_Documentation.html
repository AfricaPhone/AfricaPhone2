📡 API Connecteur Boutique

Documentation pour l'intégration du logiciel de caisse avec le système de codes promo.

Version API : v1.0
Mise à jour : 12 Janvier 2026
Statut : ✅ Production Ready

1. Vue d'ensemble

Ce point de terminaison HTTP permet à votre logiciel de caisse d'envoyer les notifications de ventes en temps réel vers la plateforme centrale AfricaPhone.

Objectif : Alimenter les tableaux de bord des partenaires/influenceurs instantanément après un achat en boutique.

2. Accès & Authentification

Paramètre Valeur
URL de Base https://us-central1-africaphone-vente.cloudfunctions.net/api_record_sale
Méthode HTTP POST
Content-Type application/json
Authentification Header x-api-key
⚠️ Sécurité : Ne partagez jamais la clé API publiquement. Pour obtenir la clé de production définitive, contactez l'administrateur système.

3. Format de la Requête

Le corps de la requête doit être un objet JSON valide :

{
  "code": "ZIDANE1",
  "amount": 150000,
  "ref": "CAISSE_01",
  "transactionId": "POS_TX_987654"
}

Détail des champs

Champ Type Requis Description
code String OUI Le code promo présenté par le client (ex: PROMO123). Insensible à la casse.
amount Number OUI Montant total de la vente en FCFA (ex: 50000). Utilisé pour le calcul de commission.
transactionId String Non ID unique de la vente dans votre système. Recommandé pour éviter les doublons.
ref String Non Identifiant du point de vente ou du caissier (ex: boutique_cotonou).

4. Réponses de l'API

✅ Succès (HTTP 200) — La vente a été enregistrée. 
{
  "success": true,
  "data": {
    "code": "ZIDANE1",
    "commission": 15000,
    "discount": 10000,
    "savedAt": "2026-01-12T10:00:00.000Z"
  }
}
❌ Code Invalide (HTTP 404) — Le code n'existe pas ou n'est plus actif. 
{
  "error": "Not Found",
  "message": "Code promo introuvable ou inactif."
}
❌ Non Autorisé (HTTP 401) — Clé API manquante ou incorrecte. 
{
  "error": "Unauthorized",
  "message": "Clé API invalide."
}

5. Exemple d'intégration (cURL)

curl -X POST https://us-central1-africaphone-vente.cloudfunctions.net/api_record_sale \
     -H "Content-Type: application/json" \
     -H "x-api-key: VOTRE_CLE_API_ICI" \
     -d '{
           "code": "ZIDANE1",
           "amount": 50000,
           "transactionId": "test_001"
         }'

6. Checklist d'Intégration

Étape Action
1 Récupérer la clé API de production auprès de l'admin
2 Configurer l'appel POST dans le logiciel de caisse
3 Envoyer un appel de test avec un code promo actif
4 Vérifier la réponse (code 200 = succès)
5 Confirmer que la vente apparaît dans le Panneau Admin
Support Technique : En cas de problème, vérifiez que le code promo est actif dans le Panneau Admin.
